ทุกอย่างประมวลผลในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดไปที่ไหน ติดตั้งเป็นแอปบนมือถือและใช้ออฟไลน์ได้

**เปิดใช้งาน:** https://panuwit2005.github.io/Private-Project/

## โครงสร้าง

```
index.html            หน้าหลัก
css/app.css           สไตล์ทั้งหมด
js/app.js             helper, ไอคอน, registry ของเครื่องมือ
js/tools/*.js         เครื่องมือแต่ละหมวด (เรียก tool({...}) เพื่อลงทะเบียน)
js/main.js            หน้าแรก, ค้นหา, ปักหมุด, modal, PWA
vendor/               ไลบรารี (lamejs, jsPDF, pdf-lib, pdf.js, qrcode-generator, jsQR, marked)
sw.js                 service worker สำหรับใช้งานออฟไลน์
```

**เพิ่มเครื่องมือ:** เรียก `tool({ id, cat, also?, icon, name, desc, keywords, render(body) })` ในไฟล์หมวดนั้น (`also` = หมวดเพิ่มเติมที่ให้แสดงด้วย)

**เพิ่มหมวดใหม่:** เพิ่มรายการใน `CATS` (`js/app.js`) → สร้าง `js/tools/<id>.js` → ใส่ `<script>` ใน `index.html` และชื่อไฟล์ใน `sw.js`
แล้ว **เพิ่มเลข `VERSION` ใน `sw.js`** ทุกครั้งที่แก้ไฟล์ เพื่อให้มือถือที่ติดตั้งแอปไว้ได้เวอร์ชันใหม่

## รันบนเครื่อง
