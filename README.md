# Lumière Tools

ชุดเครื่องมือส่วนตัวกว่า 50 อย่างในเว็บเดียว ดีไซน์ glassmorphism โทนดำ-ทอง
ทุกอย่างประมวลผลในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดไปที่ไหน ติดตั้งเป็นแอปบนมือถือและใช้ออฟไลน์ได้

**เปิดใช้งาน:** https://panuwit2005.github.io/Private-Project/

## เครื่องมือ

| หมวด | เครื่องมือ |
|---|---|
| รูปภาพ | แปลง & บีบอัด (JPG/PNG/WEBP), ปรับขนาด, ครอป/หมุน/กลับด้าน, ใส่ลายน้ำ, ดูดสีจากรูป |
| เสียง & วิดีโอ | วิดีโอ → MP3/WAV, ตัดเสียง/ทำริงโทน, บันทึกเสียง, อัดหน้าจอ, จับภาพจากวิดีโอ, อ่านออกเสียง (TTS), พูดเป็นข้อความ, ภาพปก YouTube |
| PDF & เอกสาร | รูปภาพ → PDF, รวม PDF, แยก/ลบ/หมุนหน้า PDF, Markdown Preview, CSV ⇄ JSON |
| ข้อความ | นับคำ & แปลงตัวพิมพ์, แก้พิมพ์ผิดภาษา (ไทย ⇄ อังกฤษ), ตัวเลข → คำอ่านบาท, เปรียบเทียบข้อความ, ค้นหา & แทนที่, จัดการรายการ |
| นักพัฒนา | JSON Formatter, Base64, URL Encode, Hash (SHA), UUID, Unix Timestamp, Regex Tester, JWT Decoder, แปลงสี |
| คำนวณ | เครื่องคิดเลข, เปอร์เซ็นต์, VAT & ส่วนลด, ค่างวด/ผ่อน, ดอกเบี้ยทบต้น, ภาษีเงินได้, BMI & แคลอรี่, อายุ & วันที่, หารค่าอาหาร, แปลงหน่วย |
| ประจำวัน | โน้ต, To-do, ตั้งเวลา/Pomodoro, จับเวลา, เวลาทั่วโลก, สุ่ม/ลูกเต๋า/เหรียญ, วงล้อสุ่ม, ตัวนับ, สร้าง QR (รวม Wi-Fi), สแกน QR, สร้างรหัสผ่าน |

ปักหมุดเครื่องมือโปรดได้ด้วยปุ่ม ★ — รายการปักหมุด ใช้ล่าสุด โน้ต และ To-do เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น

## โครงสร้าง

```
index.html            หน้าหลัก
css/app.css           สไตล์ทั้งหมด
js/app.js             helper, ไอคอน, registry ของเครื่องมือ
js/tools/*.js         เครื่องมือแต่ละหมวด (เรียก tool({...}) เพื่อลงทะเบียน)
js/main.js            หน้าแรก, ค้นหา, ปักหมุด, modal, PWA
vendor/               ไลบรารี (lamejs, jsPDF, pdf-lib, qrcode-generator, jsQR, marked)
sw.js                 service worker สำหรับใช้งานออฟไลน์
```

เพิ่มเครื่องมือใหม่: สร้างฟังก์ชัน `tool({ id, cat, icon, name, desc, keywords, render(body) })` ในไฟล์หมวดที่เหมาะสม
แล้ว **เพิ่มเลข `VERSION` ใน `sw.js`** ทุกครั้งที่แก้ไฟล์ เพื่อให้มือถือที่ติดตั้งแอปไว้ได้เวอร์ชันใหม่

## รันบนเครื่อง

```
python3 -m http.server 8000
```
แล้วเปิด http://localhost:8000 (service worker และบางฟีเจอร์ต้องเปิดผ่าน http/https ไม่ใช่ `file://`)
