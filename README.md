# Lumière

เว็บส่วนตัวแบบรวมหลายส่วน (portal) ดีไซน์ glassmorphism โทนดำ-ทอง ตอนนี้มีส่วน **เครื่องมือ** 138 อย่าง และรองรับส่วนอื่นที่จะเพิ่มทีหลัง (เช่น หนัง บอล)
ทุกอย่างประมวลผลในเบราว์เซอร์ ไฟล์ไม่ถูกอัปโหลดไปที่ไหน ติดตั้งเป็นแอปบนมือถือและใช้ออฟไลน์ได้

**เปิดใช้งาน:** https://panuwit2005.github.io/Private-Project/

**แปลงไม่ได้ (ต้องใช้เซิร์ฟเวอร์หรือโปรแกรมหนัก):** วิดีโอ ⇄ วิดีโอ (เช่น MOV → MP4), Word/Excel → PDF แบบตรงต้นฉบับ, PDF → Word, OCR จากภาพสแกน

**ทั้งเว็บ:** ช่องค้นหาเป็น **Smart Paste** — วางลิงก์ เบอร์โทร จำนวนเงิน วันที่ สมการ JSON หรือข้อความที่พิมพ์ผิดภาษา แล้วเว็บเสนอเครื่องมือพร้อมคำตอบ · **สำรอง & กู้คืนข้อมูล** เป็นไฟล์ JSON ไฟล์เดียว (มีแบนเนอร์เตือนถ้าไม่ได้สำรองเกิน 14 วัน)

**ลิงก์ (hash router):** `#/` หน้าแรก · `#/tools` เครื่องมือทั้งหมด · `#/tools/<หมวด>` เช่น `#/tools/invest` · `#/t/<tool-id>` เปิดเครื่องมือ เช่น `#/t/portfolio` (ปุ่มย้อนกลับปิดเครื่องมือ) · `#/<section>` ส่วนอื่นในอนาคต
ลิงก์แบบเก่า `#c/<id>` และ `#<tool-id>` ยังใช้ได้ (ถูกส่งต่อให้อัตโนมัติ)

ปักหมุดเครื่องมือโปรดได้ด้วยปุ่ม ★ — ปักหมุด ใช้ล่าสุด โน้ต To-do พอร์ต และแผนคอนเทนต์ เก็บใน `localStorage` ของเครื่องนั้นเท่านั้น

## โครงสร้าง

```
index.html            หน้าหลัก
css/app.css           สไตล์ทั้งหมด
js/app.js             helper, ไอคอน, registry ของส่วน (SECTIONS), หมวด (CATS) และเครื่องมือ (TOOLS)
js/tools/*.js         เครื่องมือแต่ละหมวด (เรียก tool({...}) เพื่อลงทะเบียน)
js/main.js            router, หน้าแรก (hub), แถบเมนูล่าง, ค้นหา, ปักหมุด, modal, PWA
vendor/               ไลบรารี: lamejs (LGPL), jsPDF, pdf-lib, pdf.js, qrcode-generator, jsQR, marked,
                      JSZip, SheetJS 0.18.5, mammoth, gifenc, heic2any, js-yaml, html2canvas
sw.js                 service worker สำหรับใช้งานออฟไลน์
```

**เพิ่มเครื่องมือ:** เรียก `tool({ id, cat, also?, fresh?, persist?, icon, name, desc, keywords, render(body) })` ในไฟล์หมวดนั้น (`also` = หมวดเพิ่มเติมที่ให้แสดงด้วย, `fresh` = ป้าย “ใหม่”, `persist:false` = ไม่จำค่าที่กรอก)

**เพิ่มส่วนใหม่ (เช่น หนัง บอล):** เรียก `section({ id, name, icon, desc, render(el) })` แล้วจะได้การ์ดบนหน้าแรก แท็บเมนู และลิงก์ `#/<id>`

**เพิ่มหมวดใหม่:** เพิ่มรายการใน `CATS` (`js/app.js`) → สร้าง `js/tools/<id>.js` → ใส่ `<script>` ใน `index.html` และชื่อไฟล์ใน `sw.js`
แล้ว **เพิ่มเลข `VERSION` ใน `sw.js`** ทุกครั้งที่แก้ไฟล์ เพื่อให้มือถือที่ติดตั้งแอปไว้ได้เวอร์ชันใหม่
